# Iris Flower Classification

A beginner machine learning practice project using Python and Scikit-learn.

### What I Practised
- Loading the Iris dataset.
- Splitting data into training and testing sets.
- Training a Decision Tree Classifier.
- Making predictions and evaluating accuracy.
- Visualising the decision tree.

### Technologies
Python, NumPy, Pandas, Matplotlib and Scikit-learn.

**Goal:** Practising and improving my understanding of Machine Learning and Data Science fundamentals as a BSc IT student.
